# Nutrition UI Mockups

These mockups capture the card-based direction for the NutriTrack front end.
Mobile is the primary platform direction; desktop mockups are included as
responsive references.

## Mobile-primary screens

- `mobile-nutrition-dashboard.png` — daily summary, weight, macros, vitamins,
  minerals, and bottom navigation.
- `mobile-nutrition-analytics.png` — weight trend, macro balance, vitamin and
  mineral analytics, and insight cards.
- `mobile-nutrition-diary.png` — food diary timeline, macro summary, vitamin
  and mineral checklist, and weight check-in.

## Desktop reference screens

- `desktop-nutrition-dashboard.png` — card-based dashboard overview.
- `desktop-nutrition-analytics.png` — analytics graph layout.
- `desktop-nutrition-diary.png` — diary card layout.
