# Inspiration Reference Board

## Purpose

Created `Insperation/index.html` as a local reference sheet for future AI-assisted frontend styling work.

This is not just a screenshot gallery. The page is organized as a structured design board so an AI can infer:

- which visual patterns are worth borrowing,
- which screens should lean dark vs light,
- how calorie and macro summaries should be prioritized,
- how reusable cards and insight tiles should feel.

## Styling Direction Captured

- Mobile-first nutrition UI
- Rounded cards with clear elevation
- Large headline metrics
- Macro rings and compact summaries
- Bottom-nav app framing
- Clear separation between primary and secondary metrics

## Guardrails

- Borrow structure and hierarchy, not brand identity
- Avoid copying product-specific iconography or wording
- Keep dashboards readable before adding decoration
- Use lighter health references for biometrics and recovery, not just food logging
