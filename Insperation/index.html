AI Styling Reference

NutriTrack Frontend Inspiration Board

This page is a structured reference sheet for future AI-assisted frontend styling work. Use it as a visual target for layout, card hierarchy, metric presentation, and mobile nutrition UX direction. Borrow the patterns, not the brands.

Core Style Direction

  • Mobile-first nutrition UI with strong dashboard hierarchy.
  • Rounded cards, generous spacing, and large headline metrics.
  • Clear macro rings, chips, and summary widgets over dense tables.
  • Bottom-navigation-centered flows with obvious daily progress.

Use This Board For

  • Choosing visual hierarchy for dashboard and diary screens.
  • Styling metric cards, ring charts, summaries, and biometrics.
  • Aligning spacing, corner radius, section rhythm, and information density.
  • Guiding dark and light mode compositions without copying a single app verbatim.

Avoid

  • Brand-specific logos, icons, and copy from reference products.
  • Overly clinical visuals that lose warmth or game-like energy.
  • Screens overloaded with text before the core metrics are understood.
  • Mixing too many visual languages on the same screen.

Dark Analytics and Logging

Use this cluster when styling screens that need to feel data-rich, goal-oriented, and immediately actionable. The standout traits are high contrast, vivid accent colors, and strong grouping around daily progress, food actions, and targets.

Dark dashboard Quick actions Macro rings

High-Contrast Dashboard Hub

Large dashboard modules, bright metric accents, and a central add action create an immediate sense of daily control.

Use For
  • Daily overview screens with calorie, macro, and streak summaries.
  • Action clusters for logging food, exercise, biometrics, or notes.
  • Showing one hero stat above secondary charts.
Avoid
  • Copying the exact visual identity or tab naming from Cronometer.
  • Overfilling the screen with too many equal-weight cards.
Dark utility flow Diary Targets

Structured Logging and Goal Setup

This set is useful for screens that need to balance progress rings with long, scrollable lists of meals or settings.

Use For
  • Diary lists where each logged item should remain readable at speed.
  • Macro target configuration with visible ratios and supporting explanations.
  • Food library and custom item flows.
Avoid
  • Dense settings copy without spacing relief or grouping.
  • Dark-on-dark contrasts that flatten important call-to-action buttons.

Light Wellness and Summary Screens

These references show a softer, more approachable wellness language. They are best for onboarding, daily check-in, or summary views where calm, clarity, and positive momentum matter more than dense analytics.

Light wellness Daily summary Food planning

Friendly Habit-Builder Aesthetic

Soft greens, rounded modules, and low-pressure information density make this a good model for gentle daily motivation.

Use For
  • Home or today screens that should feel healthy, calm, and encouraging.
  • Combining simple charts with a food plan or schedule.
  • Color-coding nutrition values without making the UI feel clinical.
Avoid
  • Overusing pastel tones where stronger contrast is needed for accessibility.
  • Reducing the nutrition data so much that power users lose detail.
Clean white cards Recent logs Macro summary

Minimal Daily Summary Layout

Strong whitespace, one big headline number, and tidy log cards make this ideal for a readable daily progress screen.

Use For
  • Top-of-screen calorie summary with supporting macros beneath.
  • Recent food or activity cards that need quick scanability.
  • Clean transitions between summary widgets and list content.
Avoid
  • Making the page so airy that important actions feel disconnected.
  • Letting white surfaces become visually flat without subtle elevation.
Minimal dashboard Meals Progress ring

Focused Macro-First Meal Screen

The hero ring and compact macro cards create a simple structure that still leaves room for meal history below.

Use For
  • Daily meal tracking screens with one dominant progress indicator.
  • Compact protein, carb, and fat cards that support quick interpretation.
  • Clear handoff from summary metrics into meal rows.
Avoid
  • Localized copy or food iconography that is too specific to the reference app.
  • Overly literal copies of the carrot-based calorie metaphor.

Cards, Widgets, and Insight Modules

These examples are most useful when designing reusable building blocks. They show how to package health metrics into tiles, rings, and lightweight comparative panels that can scale across dashboards and profile-style screens.

Insight tiles Trend cards Dashboard grid

Modular Insights Grid

This is the clearest reference for turning many health signals into a cohesive, glanceable card system.

Use For
  • Reusable metric cards with mixed chart types in the same layout.
  • Highlighting streaks, balance, weight, and weekly trend snapshots.
  • Building an insights or progress tab with modular content blocks.
Avoid
  • Too many cards per screen without hierarchy between primary and secondary metrics.
  • Using colors that break semantic meaning across cards.

Compact Health Widgets

These micro-components are useful references when a full card would be too large and a tiny summary needs to stay expressive.

Use For
  • Home screen widgets or compact dashboard rows.
  • Secondary glanceable summaries for glucose, calories, or macros.
  • Reusable small cards that still include directional feedback.
Avoid
  • Cramping too many values into a tiny footprint without visual prioritization.
  • Using detailed labels where icon-plus-metric would read faster.

Biometric Dashboard Language

Soft cards, restrained color, and precise charts make this the best reference for deeper health metrics beyond food logging.

Use For
  • Weight, body composition, recovery, or long-term wellness panels.
  • Profile or biology screens that need to feel credible and calm.
  • Blending line charts, gauges, and numeric readouts in one system.
Avoid
  • Making food-centric screens feel too medical unless that is intentional.
  • Copying exact card arrangements without adapting to our data model.

Before/After Card Hierarchy Fix

This is the strongest reminder that small spacing and content-order changes can make a nutrition dashboard feel significantly more premium.

Use For
  • Refining layouts where all the right data exists but the rhythm feels off.
  • Improving perceived polish with better grouping and alignment.
  • Teaching an AI to prefer cleaner visual hierarchy over extra decoration.
Avoid
  • Changing structure just to be different when the current hierarchy already works.
  • Focusing on small polish before the information architecture is correct.

How an AI Should Read This Board

Prefer a hybrid direction: use the dark references for data-heavy tracking screens and the lighter references for insights, wellness, and biometrics. Reuse patterns like rounded cards, clear hero metrics, compact macro summaries, and bottom-nav mobile framing. When in doubt, prioritize readable hierarchy, daily progress visibility, and a polished card system over novelty.
